# TimeTable

茨木〜神戸方面のCSV時刻表を検索し、行き・帰りの列車をダイヤグラムで表示するFlaskアプリです。

## 起動（Windows / Python導入済みの環境）

リポジトリのフォルダで以下を実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m flask --app app run --port 5050
```

ブラウザで http://127.0.0.1:5050 を開きます。停止は起動した端末で Ctrl+C。
既に仮想環境を作成済みなら、最後のコマンドだけで再起動できます。

## 乗換候補の操作

1. 「行き」で希望到着時刻（例：09:15）、または「帰り」で神戸の希望出発時刻（例：18:00）を検索します。
2. 列車線または駅箱をクリックすると、乗車中の列車を選択します。
3. 別列車の駅箱をクリックすると、乗車中の列車の同じ駅から赤線を引きます。
4. 同じ乗換候補の駅箱を再タップすると赤線を解除します。乗車中の列車を再タップすると両方解除します。
5. 列車線をクリックすると乗車中の列車を変更できます。

乗車中の列車に同じ駅箱がない場合は候補にできません。赤線は手動選択の表示であり、
乗換可否・必要乗換時間を判定しません。時刻が逆順の候補も選択できます。
到着時刻がCSVにない駅では着時刻は表示しません。

## スマホ向け全画面ダイヤUI（2026-09-11）

- 通常画面はほぼダイヤのみ。右下の固定ボタンから操作用ボトムシートを開きます。
- ボトムシート内で行き・帰り、指定時刻、検索、ズーム－／＋／リセットを操作します。
  背景タップ、閉じるボタン、Escapeで閉じられます。
- localStorageの `timetable.search` に成功した検索の `direction` と `target_time` を保存します。
  再アクセス時は条件を復元し、従来のPOSTで自動検索します。通常はシートを閉じてダイヤを表示します。
  初回・保存値が壊れている場合・検索エラー時はシートを開きます。
  保存が使えないブラウザでも手動検索は可能です。保存条件はブラウザ・接続先ごとに別です。
- 時間軸を上端、駅名軸を左端に固定。ダイヤから複製した文字の座標をスクロール・ズームに同期させます。
  時刻・駅名の文字サイズは拡大せず、時間間隔と駅間隔を拡大します。
- 希望時刻の赤い縦線は行きのみ表示します。
- 列車と乗換候補は再タップで解除。通常画面の説明・選択パネル・解除ボタンはありません。
- 100dvh、iPhoneのsafe-area、44px以上の操作ボタンに対応しています。

検索ロジック、CSV、深夜帯処理、色分け、駅箱の重なり回避は変更していません。

390px幅のEdgeで、初回、検索、再アクセス・再読み込みによる復元、シート開閉、縦横スクロール、
固定軸の座標、ズーム、再タップ解除、行きのみの赤線、帰りの復元、検索エラー復帰を確認しました。
ピンチは模擬タッチイベントで確認。iPhone実機でのピンチ・アドレスバー伸縮・safe-area表示は未確認です。
既存28テストは成功。UIを検証する1箇所の期待座標のみ、新しい左余白64pxに合わせています。
